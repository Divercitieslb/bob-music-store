# Collections — the 42 the theme expects

Every one is a **smart (automated) collection** with a single rule:

> Product **tag** — **is equal to** — *the collection title*

The products already carry those tags, so each collection fills itself.

## Fastest route

Install **Matrixify** (free tier is enough) and import
`import/collections-matrixify.csv`. That creates all 42 with their rules,
descriptions and sort order in one pass.

## By hand

Products → Collections → Create collection, for each row below. Set the
**handle** explicitly (Edit website SEO → URL handle) — if a handle is left to
generate itself and one already exists, Shopify appends a suffix and the
theme links stop resolving.
